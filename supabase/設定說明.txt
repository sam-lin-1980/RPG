Supabase 設定方式

1. 打開網站根目錄的 config.js
2. 填入：
   SUPABASE_URL
   SUPABASE_KEY（Publishable Key）

範例：

window.KA_CONFIG = {
  SUPABASE_URL: "https://你的專案.supabase.co",
  SUPABASE_KEY: "sb_publishable_..."
};

3. 不要放：
   service_role
   secret key
   database password

4. core/database.js 是全站共用資料庫模組。
   以後年級或科目資料夾不用各自放 Supabase URL/Key。

5. supabase/schema.sql 是之後正式 RPG 資料庫建議結構。
   包含：
   player_profiles
   game_results
   boss_tickets
   player_achievements
